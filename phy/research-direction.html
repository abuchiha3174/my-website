Build flowchart

One path, five stages. done = already exists (prior exploratory scripts). new = new work this fall.

▶ STAGE 1 Real-data reconnaissancedone complete

What it is

First_Pass.py / Second_Pass.py / Third_Pass.py — PCA/clustering on phase-FFT slices, IsolationForest anomaly detection across 42 pulse-width conditions, and an MLP testing whether near-future signal is predictable at all (checked against a shuffled-target control and a mean baseline).

Why it matters

Confirms the real experimental data has genuine, non-random structure worth building on — not proof of suppression yet, but the reconnaissance that justifies investing in the next four stages instead of guessing blind.

Caveat

Small-N (~42 conditions) makes the R² numbers fragile — treat as "there is structure here," not as a finished result to quote directly.

▶ STAGE 2 Standardize the datasetnew work next

What it is

Reconstruct the raw-measurement → IQ-matrix → FFT-feature → figure pipeline from Fitzpatrick's manuscript codebase, then standardize it into a clean, reusable dataset: raw_iq_timeseries/, processed_iq_matrices/, fft_phase_spectra/, fft_amplitude_spectra/, simulation_data/, metadata/ (temperature, pulse duration/ amplitude/phase, spacing, drive frequency, material, timestamp).

Why it matters

Turns a figure-generation repo into an actual ML-ready dataset — this is the "more data to train/compare against" step. Every later stage depends on this being done properly, once, rather than re-derived ad hoc each time.

▶ STAGE 3 Forecasting surrogate modelnew work new work

What it is

A model that predicts future ring-down / spectral response given pulse parameters (amplitude, phase, duration, inter-pulse spacing) — "TLS Ensemble Dynamics Forecasting." Fast enough to evaluate thousands of candidate pulses cheaply, unlike running a full physics simulation per candidate.

Why it matters

This directly fixes the original plan's stated weakness of a pulse-suppression search (too expensive to run a full simulation per candidate pulse) — train the surrogate once, then search against it cheaply.

▶ STAGE 4 Pulse suppression searchnew work new work

What it is

Evolutionary / gradient-free search over the pulse-shape space (amplitude, phase, duration, spacing), using the Stage 3 surrogate as the fitness function, looking for pulses that create destructive interference in the TLS ring-down response — suppressing the decoherence the defects cause.

Why it matters

This is the actual deliverable: directly extends the BCTDS paper's own demonstrated amplitude/phase/spacing coherent-control result, automating and optimizing what the paper did by manual sweep.

▶ STAGE 5 Validationnew work new work

What it is

Compare the best-found suppression pulse against a no-suppression baseline — on real data / the surrogate first; hardware validation on Fitzpatrick's actual BCTDS setup is a stretch goal beyond fall scope.

By Dec 1

Standardized dataset · working forecasting surrogate · a measured suppression benchmark (suppressed vs. baseline ring-down amplitude) — a complete, describable result even without a publication.
